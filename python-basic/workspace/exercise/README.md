# Java 기초 문제를 Python 문제로 변환한 학습 자료

이 자료는 `Archive.zip`에 포함된 Java 연습문제 58개 파일을 검토하여 Python 초급 학습에 맞게 다시 구성한 것입니다. 원문의 문제 의도는 유지하되 Java에 종속된 표현은 Python 방식으로 바꾸었습니다.

7. [07_클래스와_상속.md](07_클래스와_상속.md)

각 문제는 별도의 Python 파일로 작성하는 것을 권장합니다. `콘솔 실행 예시`가 있는 문제는 입력 안내 문구, 출력 순서, 줄바꿈, 종료 메시지를 포함한 **필수 출력 제약**으로 간주합니다. 예시의 사용자 입력값은 달라질 수 있지만, 프로그램이 출력하는 문구와 형식은 예시를 따릅니다. 콘솔 예시가 없는 단순 연산 문제만 출력 문구를 자유롭게 정할 수 있습니다.

콘솔 예시 안의 `...`는 반복되는 입출력을 지면상 생략한 표시이며 프로그램이 실제로 출력하는 문자열이 아닙니다.

## 변환 원칙

- Java의 배열, `ArrayList`, `Vector`는 목적에 따라 Python `list`로 바꾸었습니다.
- `HashMap`은 Python `dict`로 바꾸었습니다.
- `Calendar`는 `datetime`으로 바꾸었습니다.
- `StringBuffer`의 문자열 변경은 `str.replace(..., 1)` 또는 슬라이싱을 활용하도록 바꾸었습니다.
- Java 인터페이스와 추상 클래스 문제는 Python의 상속 또는 `abc` 모듈로 학습할 수 있게 정리했습니다.
- Java의 고정 길이 배열을 늘리는 문제는 Python 리스트의 `append()` 학습 문제로 자연스럽게 바꾸었습니다.
- 원본의 Java 전용 패키지 분리 문제 2개와 전위·후위 증감 연산자 문제 1개는 제외했습니다.
- `byte` 오버플로 자체는 Python 정수에 없으므로 제외하고, 나눗셈과 형 변환 비교 문제로 재구성했습니다.

## 검토 결과

- 원본 Java 파일: 58개

- `class02Ex/classEx.zip`은 Java 클래스 문제의 별도 중복 묶음이므로 현재 압축의 최상위 `.java` 파일만 기준으로 삼았습니다.
